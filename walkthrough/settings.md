# Settings

- Run on: after each edit (default) or only on save.
- Time limit: 5 seconds. An endless loop is stopped and the line says so.
- Memory limit: 1024 MB per run.
- Runtime: the Node.js inside VS Code (nothing to install), or the `node` on your PATH, any version.
- Values per line: 100. A loop that runs a million times keeps the first 100 values and counts the rest.

No popups, no news pages, no ads. The extension asks for a rating at most twice, after several days of use. The setting Ask For Rating turns that off.
